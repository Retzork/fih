## 1. Boss roster: the binary has exactly one boss

P2.9's PLAN line said "final-level boss per tank". The binary does not work that way:

- **`Sexy::Alien` kind 0x15 ("Cyrax") is the only boss object.** It is the only kind that
  sets `Tank+0x110`, the only kind with a special death cleanup (SS7), the only kind whose
  HP bar is unconditional (SS5), and the only enemy in the tank-5 level table
  (`Tank+0x2BC = 0x15` at session init, EV-0072).
- **Tanks 1-4's final levels have no boss object.** Their level-5 wave sets are ordinary
  alien types that keep re-rolling (P2.8 SS5.1, EV-0111):

  | level | base type / re-roll | resulting aliens |
  | --- | --- | --- |
  | 1-5 | `rand()&1 ? 9 : 3` | Sylvester + Balrog pair, or Balrog |
  | 2-5 | 9 -> `((~rand())&1) \| 4`; 10 % toggle 4/5; 5 % -> 9 | Sylvester+Balrog, Destructor/Ulysses |
  | 3-5 | `((~rand())&1) \| 6` | Ulysses (6) or Psychosquid (7) |
  | 4-5 | `rand()%5`: 0-1 -> 0xA (40 %), 2-3 -> 0xB (40 %), 4 -> 8 (20 %); mode 4 with wave > 4 turns 8 into 0xC | Psychosquid+Balrog, Destructor+Ulysses, Bilaterus |

  Their threat comes from wave composition, not from a unique damaged object, so the
  remake should treat "level 5" as a wave-table row, not as a boss scene.
- Everything else that reads like a "weak point" (Bilaterus' two 100-hp heads, the
  composite pairs) is P2.8 material.

Victory in tank 5 is therefore a single-boss encounter: kill Cyrax, then buy the free egg
piece (SS8).

## 2. Tank-5 setup (the arena)

All from P2.6 (EV-0072/EV-0073) plus SS3 below:

- Store: **only item 11 (egg piece) at slot 6, price 0**; `Tank+0x43C = 3` egg pieces
  owned, so one purchase reaches 4 and completes the level.
- `Tank+0x2BC = 0x15` - the level's alien selection, so the very first wave of the level
  is a boss spawn.
- `Tank+0x2C0 = 300` (not 3000) - the boss arrives **300 ticks / 8.3 s** after level start.
  The wave block resets the countdown to 3000 after every spawn, but it never ticks again
  while the boss lives (SS4).
- Pets: `FUN_005498B0` creates pets 0..0x11 (Stinky..Gash) unconditionally - no ownership
  or selection filter, and Angie (0x12), Presto (0x13) and the bonus pets are excluded.
- No fish, no food, no weapon upgrade in the store: the fight is pets + the player's
  laser only.
- Decoration/backdrop: ordinary tank-5 set (P2.6).

## 3. The boss object

Ctor `FUN_004ECFA0(x, y, 0x15)` (P2.8 SS2/SS3, EV-0113):

- hp: `i = clamp(profile+0x54 - 1, 0, 20); hp = 5000 - (i * 2500) / 20` = **5000 - 125*i**
  (integer math), so **5000 down to 2500** in 125 steps; `+0x1F8` receives the same value.
- speed divisor `+0x1B8 = 2.0`; box 160x160; sprite `DAT_005e8cb8` (`IMAGE_BOSS`);
  animation frame counter `+0x1C0 = 1`; intro timer `+0x158 = 15`; hurt flash `+0x200`.
- **One image, no frame variants**: `FUN_004DAE20`'s kind-0x15 case binds `DAT_005e8cb8`
  and never changes `local_1c` (frame row) - so there is no damaged/shell/rage artwork.
- Timers initialised for the attack loop: `+0x1DC = 0` (wave timer), `+0x1E0 = 0`
  (minion timer), `+0x1E4 = 300` (wave period), `+0x1E8 = 75` (minion period).
- Movement is the shared wander (P2.8 SS6): speed 2.0, clamped to `x [-10,490]`,
  `y [85,290]`, quadrant re-roll every 20 ticks with a 10 % chance.

Spawn (`FUN_00545620` type 0x15, P2.8 SS4): `Tank+0x4EE = 1`, `new(0x208)` +
`FUN_004ECFA0(x, y, 0x15)`, pointer stored at **`Tank+0x110`**, registered, and
**`Tank+0x3E4 = 10`** (pet capacity 10 for the fight). Sound `DAT_005e8c9c`.

## 4. Attack loop (corrects EV-0114's wording)

`FUN_004F03D0` (the shared gate/bite dispatcher) carries the whole Cyrax AI. Kind 0x15
skips the eat logic and runs two independent timers (EV-0117):

```c
/* minion timer: every +0x1E8 = 75 ticks */
if (++(+0x1E0) >= +0x1E8) { +0x1E0 = 0; FUN_00545580(+0x30, +0x34); }

/* wave timer: only while Tank+0xB8 and Tank+0xF4 are both empty */
if (list_empty(Tank+0xB8) && list_empty(Tank+0xF4) && ++(+0x1DC) >= +0x1E4) {
    +0x1DC = 0;
    Tank+700 = rand()%6 + 4;                    /* 4..9 - an alien TYPE */
    FUN_005475B0(Tank+700, 1);
}
```

- **`FUN_00545580(x, y)` spawns a Minisylvester, not a projectile.** Body (EV-0117):
  alloc 0x208, `FUN_004ECFA0(x + 0x28, y + 0x28, 0x14)`, register via `FUN_00542EE0(obj,1)`,
  list-add through `[manager+0x10]`, `FUN_00544800`, `FUN_0053AA40` (UI refresh). So Cyrax
  drops a 1-hp Minisylvester at his own position every **75 ticks (2.08 s)**.
- **`FUN_005475B0(type, play_sound)` is the generic wave spawner wrapper**: two
  `FUN_0040AEB0()` rolls and `FUN_00545620(type, rand%0x1C2 + 0x14, rand%0xC3 + 0x69,
  play_sound)`, i.e. a random point at `x 20..469`, `y 105..299`.
- Because the argument is `rand()%6 + 4`, the boss periodically spawns **a random
  mid-tier alien of type 4-9**: 4 Gus, 5 Destructor, 6 Ulysses, 7 Psychosquid,
  8 Bilaterus (separate class), 9 Sylvester + Balrog composite. Every 300 ticks
  (8.3 s), and only when nothing alien-side is already alive (`Tank+0xB8` aliens and
  `Tank+0xF4` projectiles empty) - so it is a "field is clear" pulse, not an overlapping
  wave.
- `Tank+0x700` is the scratch slot that forwards the rolled type. It lies outside the
  0x504-byte Tank allocation, so it is read back immediately by the same call and has no
  other observable role (bounded note, not a field).

Consequence for the remake: the fight is a **two-clock pressure system** - a 2.08 s stream
of 1-hp pop-corn minions plus an 8.3 s "spawn a real alien when the field is clear" pulse -
and there is **no HP-threshold phase** anywhere in the binary (no code compares `+0x1F0`
against a fraction; the draw code has a single frame). The wiki's "three phases" phrasing
is not backed by any branch we can find; the only escalation is `profile+0x54` scaling hp
down across attempts (SS8).

## 5. HP bar (draw code recovered down to the instruction)

`FUN_004DAE20` (Alien::Draw) draws the bar **after** the sprite, gated by

```c
if (kind == 0x15 || (Tank+0x178 != 0 && Tank+0x3C8 != 5)) { ... }
```

i.e. Cyrax always has one; ordinary aliens only when the tank flag `+0x178` is set and the
tank is not tank 5 (`+0x3C8 == 5`). Exact geometry (EV-0118, from the function dossier's
assembly at `0x4DB131-0x4DB1B6`):

```
tube_w  = [DAT_005e8e3c + 0x24]          ; source image width
tube_h  = [DAT_005e8e3c + 0x28]          ; source image height
y       = [Alien+0x3C] - 3               ; box height (160) - 3 = 157
w       = ftol(tube_w * hp / hp0)        ; FILD tube_w; FMUL +0x1F0; FDIV +0x1F8
w       = clamp(w, 0, tube_w)            ; negative -> 0, > tube_w -> tube_w
rect    = CRect(0, 0, w, tube_h)
draw    FUN_00455E40(DAT_005e8e3c, 10, y, &rect)   ; tube, clipped to the hp width
draw    FUN_00455D20(DAT_005e8eb8, 10, y)          ; fill/overlay image
```

- x is the constant **10** (left inset inside the 160-wide sprite box), y is
  **box height - 3**, so the bar sits along the bottom edge of the alien's own sprite.
- The two images are the resource `IMAGE_HEALTHBARTUBE` (`0x59CD64`) and `IMAGE_HEALTHBAR`
  (`0x59CD78`) entries of `resources.xml` (EV-0022/EV-0024 string inventory), resolved
  through the globals `DAT_005e8e3c` / `DAT_005e8eb8`.
- The `+0x178` flag is a Tank flag written outside every function decompiled so far
  (bounded negative: no writer located); treat it as "show alien health bars" and keep it
  configurable in the remake.
- **`FUN_00564160` is the CRT float->int helper, not a resource lookup.** Its body is
  `ROUND(in_ST0)` (`_ftol`-style, reads the x87 stack top; the dwords Ghidra printed as
  its "arguments" are call-setup leftovers) (EV-0118). This corrects P2.8 SS9's reading of
  `FUN_005442C0(FUN_00564160(...), FUN_00564160(...), frame, kind, facing)` - the two
  "lookups" are two `ftol` conversions, so the first two arguments of `FUN_005442C0` stay
  unexplained and are re-opened in Q-0020.

## 6. Damage and weak points (the shot hit handler `FUN_004FA6F0`)

The player laser does not damage aliens through a separate weapon system: it calls
**`Alien::HitTest(x, y)` = `FUN_004FA6F0`** (EV-0120), which is where all of P2.9's
"damage" questions resolve:

1. **Box test first.** The click point must be strictly inside the alien's own
   160x160 box: `+0x160 < x < +0x160+160` and `+0x168 < y < +0x168+160`. There is no
   sub-region, no head/mouth/eye test, and no direction requirement - **Cyrax has no weak
   point**; any point inside the sprite hurts.
2. **Hit cooldown.** `if (+0x200 > 0) return 0;` - an alien that was hit in the last 10
   ticks ignores further shots. Every accepted hit ends with `+0x200 = 10`, so the maximum
   rate is one hit per 10 ticks (~3.55 hits/s at 36 Hz) per alien.
3. **Damage formula** - damage is `3 * Tank+0x3E4` for every kind except 5/6:

   ```c
   kind 5 or 6 (Destructor/Ulysses): hp -= Tank+0x3E4 * 2 + 2;
   everything else (incl. Cyrax):    hp -= Tank+0x3E4 * 3;
   ```

   `Tank+0x3E4` is the field P2.6 tracked as "pet slots" (2 at level start, 8 in demo,
   10 when the boss spawns) and the field store item 10 ("upgrade weapon") increments up
   to 12 (EV-0057). Sharing it between pet capacity and shot damage is what makes the
   numbers work: with the boss-forced value 10, a Cyrax hit does **30** damage, so 5000 hp
   needs 167 hits (1670 ticks = 46.4 s of continuous shooting), and the 2500-hp version
   needs 84 hits (23.3 s). The normal-play value cross-checks against the wiki's hit counts:
   at `Tank+0x3E4 = 2` a hit does 6, which matches Sylvester 50 hp / 10 hits, Balrog 130 hp /
   22 hits and Bilaterus 100 hp / 17 hits per head (EV-0121, `wiki-refs.md` §2). **P2.10 must
   confirm the field's double role** (the store label and the capacity use are in P2.5/P2.6; the
   damage use is here).
4. **Special cases** (not boss-related, but they sit in the same function): a *resting*
   Psychosquid (kind 7, `+0x204 != 0`) **heals** by `Tank+0x3E4 * 3` per shot and shows
   the hint `"Stop shooting! Alien regains health!"` (0x599188) when no boss is alive;
   and a Psychosquid shot below 100 hp is forced back to sleep (`+0x204 = 1`,
   `+0x19C = 1`, `+0x1AC = 10`, `+0x194 = rand()%100`), outside demo.
5. **Knockback.** After the damage step the function pushes the alien away from the
   click: it compares the point against the inner 60x60 and 100x100 sub-boxes and writes
   `+0x170` (vx) / `+0x178` (vy) as `+0x1B8 * (+-2.5 / +-3.0 / +-3.5 / +-4.0)`; the exact
   quadrant-to-vector table is in the raw listing. Kinds 5/6 skip it while `+0x1AC != 0`.
6. **Death.** `if (hp <= 0) { FUN_004F9C70(); return 1; }` - a shot kill enters the death
   path of P2.8 SS9. The `from_shot` argument is not visible at this call site (the melee
   path passes 1 explicitly), so the diamond drop for shot kills is taken as 1 per P2.8
   but recorded as a small open detail (Q-0022 note).

Other damage sources: pet melee `FUN_004FB5B0` (kind 5/4 take 0.25 / 0.5, **every other
kind takes the full 1.0 / 3.0** - Cyrax has no melee resistance, 3.0 per Gash touch).
Feedback: `+0x200` drives the white flash in `FUN_004DAE20`; for kind 4 only, the flash is
suppressed while a boss alien is alive, so Gus stops flashing during the Cyrax fight.
No shield, no regeneration and no invulnerability window exists for kind 0x15 in any
decompiled body - the boss can only be worn down. The wiki (403 on 2026-10-29, as in P2.8)
could not be used to cross-check any of this.

## 7. Defeat: the cleanup handshake (`FUN_004F9950`)

The death path `FUN_004F9C70(1)` ends by calling `FUN_004F9950()`, which is **boss-only**
(EV-0118):

```c
if (Alien+0x1EC == 0x15) {
    Tank+0x110 = 0;                 /* boss slot released */
    Tank+0x4F4 = 1;                 /* freezes the wave clock (its gate needs 0) */
    for each obj in Tank+0xBC: FUN_005420E0(&obj);
    collect Tank+0xB8 (aliens) + Tank+0xDC (projectiles) into a vector;
    for each: FUN_004D6830(1);      /* warp-out/remove */
}
```

So killing Cyrax **clears the field**: every surviving alien (including Minisylvesters)
and every enemy projectile is torn down, and no further waves can start because
`FUN_00547610`'s countdown requires `Tank+0x4F4 == 0`.

Death effects come from the generic path (P2.8 SS9): no debris loop, `FUN_005442C0`
animation, sounds. **No diamond**: the coin drop is gated on `Tank+0x110 == 0` *before*
the unregister runs, so Cyrax never drops the 200-value diamond; only his minions do
(when no boss is alive - i.e. never while he lives, which makes Minisylvester diamonds
tank-5-impossible as well).

## 8. Victory and loss flow

- **Completion**: buying the free egg piece (`FUN_00545960`, EV-0067/EV-0115) increments
  `Tank+0x43C` 3 -> 4, records `Tank+0x3FC`, clears `Tank+0x4EE`, calls `FUN_0053C2D0`,
  then `FUN_00501370` advances to tank 5 / level 2. For tank 5 it copies the empty pet
  slots into `DAT_005e8fe0` / `DAT_005e9080` (credits jokes) before `FUN_00514510`
  writes the record; then the Presto hatch (index 19 + 5000 shells) and the victory-gate
  state (`FUN_00517C70`/`FUN_0051E060` -> InterludeScreen, EV-0071).
- **The two gates on the egg purchase** are `FUN_00538090(0xB)` (the egg store object must
  exist; it returns 0 when the item's slot `A[11]` is negative, EV-0057) and
  `FUN_00540B30(price, quiet)` = **`Tank::SpendMoney`**: returns 1 after subtracting from
  `Tank+0x3F0`, returns 0 (with sound `0x112`, `+0x450 = 70` cooldown and a money == 0
  tutorial block) when `money + FUN_0053A0B0() < price`; mode 5 is exempt entirely
  (EV-0119). **Neither gate checks `Tank+0x110`**: no decompiled path stops the player
  from buying the free egg piece while Cyrax is alive, so "you must kill the boss first"
  is not enforced by the purchase handler. Marked open (Q-0021): the store UI
  (`FUN_00549380`/`FUN_0053EAF0` child code) is not decompiled, so a UI-level greying is
  not excluded.
- **`profile+0x54` scaling**: in the tank update (`FUN_00547610`), inside the
  `Tank+0x2A5 == 0 && mode != 5` block, the **tank-5 branch** runs when the list
  containers `Tank+0xB4` and `Tank+0xB0` are both empty:

  ```c
  FUN_0053DB80();
  boss = Tank+0x110;  Tank+0x4EE = 0;
  if (boss != 0 && boss->hp0 - boss->hp > 1000.0) (*(int*)(profile+0x54))++;
  /* then dialog events 0x11/0x12/0x13 through FUN_0054B5B0 */
  ```

  The condition itself is exact (boss alive, more than 1000 damage dealt, lists empty);
  the sibling non-tank-5 branch is the "no fish left" loss handler, which makes the
  tank-5 branch read as the **loss/retry** handler rather than a kill counter. The ctor
  then subtracts 125 hp per counted event, so repeated losses make Cyrax weaker (down to
  2500). Recorded as open (Q-0022): "attempt/loss counter" vs "defeat counter" is a naming
  question, the numbers are not.
- **`Tank+0xB0`/`+0xB4`** are list containers (begin/end at +4/+8) that the tank-5 branch
  and the tank-5 score record read; no decompiled body fills them (bounded negative).
- Credits: still Q-0016 (P2.6); this note adds no new credits trigger.

## 10. Implementation spec for P4

1. **One boss scene, no per-tank boss.** Model tank 5 level 1 as `boss = "cyrax"`; tanks
   1-4 level 5 stay wave-table rows (SS1).
2. **Setup**: egg pieces = 3, store = one free egg item at slot 6, alien selection
   `type = 0x15`, arrival countdown 300 ticks (8.3 s at 36 Hz), pets 0..0x11 pre-created,
   pet capacity set to 10 when the boss spawns.
3. **Boss stats**: `hp = 5000 - 125 * clamp(profile.cyrax_offset - 1, 0, 20)`,
   speed divisor 2.0, 160x160 box, wander quadrant AI, y clamp 85..290, 15-tick intro.
4. **Two clocks**: minion spawner every 75 ticks at boss position + (40, 40);
   alien-wave pulse every 300 ticks *only when no alien and no projectile is alive*,
   spawning `type = rand() % 6 + 4` at `(rand()%450 + 20, rand()%195 + 105)`.
   Do not implement fireball projectiles - there are none.
5. **Wave clock**: frozen while `boss_alive`; after death set `no_more_waves = 1`
   (`Tank+0x4F4`).
6. **HP bar**: always for the boss; for other aliens only when the "show bars" tank flag
   is set and tank != 5. Draw at `(sprite_x + 10, sprite_y + box_h - 3)`, width
   `clamp(tube_w * hp / hp0, 0, tube_w)`, tube image + fill image, `IMAGE_HEALTHBARTUBE`
   / `IMAGE_HEALTHBAR`.
7. **Damage**: single hp pool, no weak point, no invulnerability. Shot damage
   `3 * Tank+0x3E4` (30 at the boss-forced value 10, 6 at the normal level-start value 2;
   EV-0121), at most one hit per 10 ticks per alien; melee 1.0 / 3.0 from pets
   (Itchy / Gash); knockback from the same handler. Flash on `+0x200`.
8. **Death**: release the boss slot, freeze waves, wipe all aliens + enemy projectiles,
   play the generic alien death effects, **no coin**.
9. **Completion**: allow the free egg purchase per the binary (SS8) but gate it on the
   boss being dead as a deliberate remake decision - record it as a divergence until
   Q-0021 is answered.
10. **Counter**: increment `profile+0x54` when the boss fight ends with > 1000 damage
    dealt and no minions left; hp scaling reads it back on the next run.
11. **Unknowns to keep parameterised**: `Tank+0x178` writer, `Tank+0xB0/0xB4` contents,
    `FUN_004D6830`'s warp-out visual, and the `from_shot` argument at the shot-kill call
    site.
