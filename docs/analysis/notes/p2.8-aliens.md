## 1. Identity: kinds, species, and the Q-0011 answer

Q-0011 asked where the hostile alien classes are. Answer: **every hostile alien
except Bilaterus is one class, `Sexy::Alien`** (vtable `0x59740C`, ctor
`FUN_004ECFA0(x, y, kind)`, alloc 0x208, game type id `+0x8C = 0x16`). The
species are *kind values*, not classes; the kind drives stats, sprite, sound and
attack code. This is why no Sylvester/Balrog/Gus/... RTTI names exist.

Q-0011 is ANSWERED (EV-0110). The only hostile-alien classes in the module are
`Sexy::Alien` (all species + Cyrax + Minisylvester), `Sexy::Bilaterus` (+
`BilaterusHead`, `BilaterusBone`) and the projectile classes `Sexy::Missle`/
`Larva`. `DeadAlien` is a corpse object, not a spawnable alien.

Kind -> species binding evidence comes from three independent places that agree:

1. per-tank demo pools (`FUN_00537C20`) and per-level assignments (`FUN_00541200`),
2. composite waves (`FUN_00545620`) whose pairs match the wiki's multi-alien
   battles,
3. the draw switch in `FUN_004DAE20` (one image pointer per kind) plus the
   per-kind stat/attack branches.

### 2.2 `Sexy::Bilaterus`

- ctor `FUN_004FE000(x, y)`, alloc `0x178`, type id `+0x8C = 0x17`, Update
  `0x4FE250`, vtable slots 17 `0x4DBE40` and 21 `0x4DBF20` (EV-0112).
- `+0x158` head A (`FUN_004EE210(this, x, y, 1)`), `+0x15C` head B
  (`FUN_004EE210(this, x, y, 0)`), `+0x160` list of 6 bones
  (`FUN_004EDD30`), `+0x164` byte "head lost", `+0x168` int 8, `+0x16C` int 15
  (setup countdown), `+0x170` int swap counter.
- Both heads and all bones are registered through `manager+0x320` (the object
  list) as independent objects.
- 50 % of spawns call `FUN_004FB1C0()` immediately (start with the other head
  active), otherwise play sound `0x131`.
- Update: warp-out branch (mode 5, `+0x28 > 0x10E0`) -> warp-hole effects for
  both heads, sound `0x136`, `FUN_004D6830`; then `+0x16C` setup countdown;
  `+0x170++` and, while no head has been lost (`+0x164 == 0`), every 1000 ticks
  call `FUN_004FB1C0()` (swap the active head) and reset the counter. Head A
  update (`FUN_004F0EA0`), 6 bones (`FUN_004EDEA0`), head B update, and finally
  if head A `+0x1D8 <= 0` call `FUN_004FB4C0` (destroy/swap the head; from
  P2.7: spawns effect kinds 4/5, sets `+0x164 = 1`, clears `+0x15C`, sounds
  `0x11D`/`0x11E`).

## 3. Per-kind tuning (ctor `FUN_004ECFA0`)

| Kind | hp | speed `+0x1B8` | box | notes |
| --- | --- | --- | --- | --- |
| 0 | unset | unset | 160 | falls through every stat branch |
| 1 | 50.0 | 2.0 | 160 | |
| 2 | 60.0 | 1.6 | 160 | |
| 3 | 130.0 | 1.2 | 160 | |
| 4 | 100.0 | 1.6 | 160 | flash suppressed while a boss alien exists |
| 5 | 150.0 | 1.2 | 160 | y forced to 290, int y 280 |
| 6 | 220.0 | 3.5 | 160 | y forced to 290, int y 280 |
| 7 | 260.0 | 0.5 rest / 2.0 awake | 160 | cycle timer 200/400 |
| 8 | heads 100 x2 | - | - | separate class |
| 0x14 | 1.0 | `(rand()%5)/10 + 0.8` = 0.8-1.2 | 80 | cycle 200/400, flash 30 |
| 0x15 | `5000 - 125*clamp(profile+0x54-1, 0, 20)` = 2500-5000 | 2.0 | 160 | boss |

- Speed is a *divisor*: every update does `x += vx/speed`, `y += vy/speed`, so a
  larger `+0x1B8` is slower travel.
- `profile+0x54` is the Cyrax hp-scaling counter: the wave block increments it when
  the boss object took more than 1000 damage (`+0x1F8 - +0x1F0 > 1000`), and the
  ctor subtracts 125 hp per counted step (EV-0113). The increment condition is exact
  (EV-0119); whether it counts losses or defeats is open (Q-0022).
- **Demo override** (`manager+0x880 != 0`): hp is overwritten with
  `rand()%100 + 150` (Gus: `rand()%50 + 70`) and the attack period `+0x1A8`
  becomes 144. Demo aliens are therefore uniformly tougher; do not use demo
  tuning for the remake.
  The demo flag is this byte read directly. Do **not** reuse
  `FUN_004D80C0()` as a demo test: it is `dword[this+0x19C] in {3,4,5}`, and on an
  `Alien` the same offset is a byte flag (Psychosquid's once-only sleep), so the
  predicate means nothing here (EV-0130).

## 4. Spawn pipeline (`FUN_00545620`)

`FUN_00545620(type, x, y, play_sound)` is a `Tank` method; x/y are the two
spawn points the wave block rolled into `Tank+0x2CC..+0x2D8`.

- `type 9` -> spawn 1 then 3; `type 0xA` -> 7 then 3; `type 0xB` -> 5 then 6;
  `type 0xC` -> 3 then 8. The second spawn uses the second coordinate pair.
- `type 8` -> `new(0x178)` + `FUN_004FE000(x, y)`; registered with
  `FUN_00542EE0(obj, 1)` only (no `FUN_00544800`).
- `type 0x15` -> `Tank+0x4EE = 1`; `new(0x208)` + `FUN_004ECFA0(x, y, 0x15)`;
  store the pointer at `Tank+0x110` (boss), register, and set
  `Tank+0x3E4 = 10` (pet capacity 10 for the boss fight).
- any other type -> `new(0x208)` + `FUN_004ECFA0(x, y, type)`; registered with
  `FUN_00542EE0` and `FUN_00544800`.
- After spawning: `FUN_00539AD0(0)`, `FUN_0053AA40()`, and if `play_sound`:
  `4` -> `DAT_005e8e98`, `5` -> `DAT_005e8bc8`, `6` -> `DAT_005e8b6c`,
  `7` -> `DAT_005e89fc`, `0x15` -> `DAT_005e8c9c`, `1/2/3` -> `DAT_005e8c6c`,
  `8` -> none. (Kinds 1-3 share one warning voice, so the audio does not
  separate Sylvester from Balrog.)

`_DAT_005e8f18 = [manager+0x484] - 0xD8` is written at entry (a global used by
the spawn helpers; meaning open).

## 5. Wave clock (`Tank+0x2C0`, `FUN_00547610`)

The countdown starts at **3000 ticks (83.3 s at 36 Hz)** and only advances when

- `Tank+0x2BC != 0` (an alien type is selected for the level),
- `Tank+0x110 == 0` (no boss alien alive),
- `Tank+0x4F4 == 0`,
- and the three object lists `Tank+0xB8`, `Tank+0xDC`, `Tank+0xF4` are all
  empty (no alien / projectile alive).

That last rule is the "one wave at a time" contract: the next wave cannot start
while anything alien-side is still on screen.

Milestones while the countdown ticks down:

| Value | Action |
| --- | --- |
| 276 (0x114) | tutorial message ids 1-3 (and 4-6 / 7-9 on other tanks); skipped in demo/mode 5 |
| 275 (0x113) | prep: warp-hole object at `Tank+0x118` (anim `0x112`, rects `(255,50,50)` and `(100,20,20)`); rolls the two spawn points `x = rand()%450 + 20`, `y = rand()%195 + 105` (challenge: `rand()%450+20` / `rand()%195+105` again); in mode 5 calls the VT spawner instead |
| 33 (0x21) | warning sound when `Tank+0x4FE != 0` |
| 30 (0x1E) | `FUN_00543F40()` warning animation when `Tank+0x198 != 0` and tank index != 5 |
| 1 | `FUN_0054B1A0()` event; challenge also flips `Tank+0x4DE` at 100 for tank3 L4 with a composite type |
| 0 | spawn wave, mode-4 extra spawns, re-roll the type for the next wave, `Tank+0x45C++`, countdown = 3000 |

At 0 the block also sets `Tank+0x2C4 = 0x23` (35) and clears the bytes
`Tank+0x4ED`/`Tank+0x4EC`.

### 5.1 Type re-roll (after each spawn)

Base assignment comes from `FUN_00541200` (P2.6 §8). The wave block then adjusts
it before the next wave:

- tank1 L5: `rand()&1` -> 3 else 9.
- tank2 L5: if the type is 9 -> `(~rand()) & 1 | 4` (4 or 5); then 10 % ->
  toggle 4/5, else 5 % -> 9.
- tank3 L2: 10 % -> toggle 4/5. tank3 L5: `(~rand()) & 1 | 6` (6 or 7).
- tank4 L3: `rand()&1` -> 4 else 10. tank4 L4: `rand()&1` -> 8 else 11.
  tank4 L5: `rand()%5` 0-1 -> 10 (40 %), 2-3 -> 11 (40 %), 4 -> 8 (20 %);
  then in mode 4 with wave counter > 4 an 8 becomes 0xC.
- mode 4 also adds `Tank+0x45C / d` extra spawns at countdown 0 (d = 4/5/5/6 by
  tank 1/2/3/4, minus one more when the type is 0xC), and paints the warp hole
  at `Tank+0x2C0 == 2999` on those extra waves.
- demo (`manager+0x880 != 0`) ignores all of the above and calls
  `FUN_00537C20()` (pools tank1 {2,3}, tank2 {2,3,4,5}, tank3 {3,4,5,7,6},
  tank4 {3,4,5,7,6,8}; tank 5 has none).
- mode 5 (Virtual Tank) calls `FUN_005394E0()` instead of the per-tank re-roll,
  and `FUN_00539330()` at the 275 prep tick.

Kind 0 is reachable only because tank1 L1 assigns type 0; `FUN_00545620` then
takes the default branch and builds a kind-0 object with no stat branch and no
draw case. Whether the level ever lets that wave fire (the countdown guard
`Tank+0x2BC != 0` is satisfied by 0) is unresolved - see Q-0020 and the
bounded negative in §10.

## 6. Movement and shared AI (`FUN_004FD560`)

Order inside `Update`:

1. bail if `Tank == 0` (no tank) or `Tank+0x94 != 0` (paused);
2. `FUN_004F22C0()` base timer tick (also decrements `+0x1E8`-family timers on
   other classes);
3. mode 5 only, kinds 5/6: vertical ramp - at `y >= 280` snap y to 290 and zero
   vx/vy, otherwise `vy += speed * 0.4`;
4. intro: while `+0x158` counts down from 15 and more than 8 remain, add a
   `+-3` horizontal drift (`local_8`) and return early;
5. `FUN_004F03D0()` - the attack/eat gate (§7). Non-zero => skip wander;
6. wander steering (see below);
7. Psychosquid cycle (§8.3);
8. clamp to the playfield, then integrate position;
9. decrement `+0x200` (flash) and `+0x1A0`;
10. kind 5 / kind 6 salvo logic (§8);
11. `slot 0xA4(rand, rand)` animation, `FUN_004DAA00()`;
12. if `+0x1F0 > 0` -> return; else if mode 5 and `+0x28 > 0x10E0` -> warp out
    (effects, sound 0x136, `FUN_004D6830(1)`); else `FUN_004F9C70(1)` (die).

Clamps: kinds other than 0x14 stay in `x [-10, 490]`, `y [85, 290]`;
Minisylvester in `x [10, 540]`, `y [95, 370]`. Out-of-band values are snapped to
the bound (not wrapped).

Wander: `+0x1D0` selects a quadrant - 0 -> target vx -1.5, 1 -> +1.5,
2 -> target vy -1.5, 3 -> +1.5 (kinds 5/6: only `+-1.0` horizontal, vy left
alone). `+0x180`/`+0x188` are stepped 0.1 per tick toward the target and
`+0x1D8` counts to 20, after which a 10 % roll re-picks the quadrant. Kinds 5/6
additionally nudge `+0x170` toward zero (0.8 steps) or away (0.55 steps) on a
`+0x1D0 % 5` pattern, and pin it to `+-0.1` while `+0x1AC >= 1`.

## 7. Attack gate and eating (`FUN_004F03D0`)

`FUN_004D4580()` is the gate: it returns 1 when a boss alien is alive
(`Tank+0x110 != 0`) and otherwise returns `FUN_005392A0()`. That predicate is a Tank
method (EV-0116) that is true when the fish list `Tank+0xA0`, `Tank+0xA4` or the Penta
list `Tank+0xD0` is non-empty, or when any of `FUN_004E3ED0`/`FUN_004E3F00`/
`FUN_004E3F30`/`FUN_004E3F60` is true. The wave block reuses it as its level-complete
test, so the reading is "fish are still swimming / the level is still running"; the four
sub-predicates are the part still bounded (Q-0020).

When the gate is closed the alien may still act if it is Gus with pellets in the
water (`Tank+0xAC` list non-empty) or a boss alien is alive; Cyrax always falls
through to its own logic.

With the gate open:

- kinds 5 and 6 never eat (they shoot, §8),
- a resting Psychosquid (`+0x204 != 0`) never eats,
- every other kind calls `FUN_004E8B60()` (target pick) and, on success,
  `FUN_004ED460()` (eats it) and returns 1 so the wander step is skipped.

`FUN_004E8B60` picks the *nearest* eligible target from the alien's centre and
clears the byte `+0x190`, which it sets to 1 when the chosen target is a pellet:

- **Gus (kind 4)** scans the falling-food list `Tank+0xAC`; a pellet is eligible
  when `pellet+0x198 < 1` and `pellet+0x194 != 2` (the breeding/special pellet is
  refused), and the chosen pellet gets a 2500-unit distance bonus so pellets win
  over fish.
- **everyone else** scans `Tank+0x108` for objects with `+0xAC < 0` (creature
  marker) and `+0x120 < 1`: species 5-0xA unconditionally, type 0 through
  `FUN_00500FF0`, and 0x14/0x15 only while a boss alien is alive. `FUN_00503580()`
  must also pass, and a Gus still in his damage flash (`+0x1A0 > 0`) skips the
  fish scan.

So "Gus eats pellets, everyone else eats fish" is a target-list split inside one
function, not a special case in the attack code.

`FUN_004ED460()` is **not** the bite - it is the *approach* step the gate runs every
tick while a target exists. It re-picks the target with `FUN_004E8B60()` and steers
`+0x170` (vx) / `+0x178` (vy) toward it:

- the alien point is its box centre `(+0x160, +0x168) + 80` (Minisylvester `+40`);
- the target point is the target's int `(+0x30, +0x34)` + 20 for a Gus pellet
  (`+0x190` set) and + 40 for everything else;
- vx steps 0.1 per tick while `|vx| < 1.8`; vy steps 0.1 per tick (`0.3` with a
  `3.0` ceiling for Gus on a pellet) while `|vy| < 1.8`;
- it then calls `FUN_004E8F70()` and returns 1 while a target exists, which is what
  makes `FUN_004F03D0` skip the wander step.

So eating is a **chase**: the alien accelerates toward its chosen target and the
bite runs every tick a target is held. A flashing non-Gus alien (`+0x1A0 >= 1`)
approaches but does not bite.

### 7.1 The bite (`FUN_004E8F70`)

The bite is a centre-to-centre reach test plus a virtual handshake (EV-0116):

- **Gus (kind 4)** scans the pellet list `Tank+0xAC`; a pellet is in reach when Gus's
  centre lies inside `pellet.x - 0x19 .. pellet.x + 0x41` (same in y), `pellet+0x198 == 0`
  and this alien's `+0x200 < 6`. The pellet is then removed (`FUN_004D9570`, the helper
  the fish consume uses), `+0x200 = 10` (10-tick bite cooldown) and `FUN_005384C0()`
  runs. **The bite costs Gus `+0x1F0`**: 30/25/20 for pellet variants 3/5/4,
  `quality*2 + 4` for the other variants (`FUN_004E3E00`), 20 for a star potion
  (`+0x188 == 3`, which also plays sound `0x11D` and throws 1-3 debris pairs), 8 in
  demo. `+0x1F0` is the hp pool, so a fed Gus loses health; the gameplay intent of
  that is open (Q-0020).
- **everyone else** scans `Tank+0x108`, skips objects with `+0xAC >= 0` or `+0x120 > 0`,
  and tests `|dx|`/`|dy|` between centres against `+-0x2D`/`+-0x41` (`+-0x1E` both for
  Minisylvester, `+-0x46`/`+-0x55` for target type 6). On a hit it calls the alien's
  vtable slot 77 (the index Fish uses for `consume`) and the target's slot 75, then
  returns. Target eligibility: types 5-0xA always, type 0 when `FUN_00500FF0()` returns
  0, 0x14/0x15 only while a boss alien is alive.

## 8. Per-kind attacks

### 8.1 Destructor (kind 5) - 3 homing missiles

`+0x1A4` counts up to `+0x1A8` (75). Then, if `FUN_004D4580()` is open, it
fires up to three missiles through `FUN_004E8DF0(1)` (target picker) +
`FUN_00544130(x, y, target, 0)` at offsets `(+90,-35)`, `(+105,-30)`,
`(+120,-25)` when facing right, or `(-10,-35)`, `(-25,-30)`, `(-40,-25)` when
facing left. Sound `0x128`, next delay `rand()%50 + 150` (300 in demo), and
`+0x1AC = 10` if anything was fired. In demo only the first missile is created.

### 8.2 Ulysses (kind 6) - 2 energy balls

`+0x1A4` counts to `+0x1A8` (75). 15 ticks before the shot
(`+0x1A4 == +0x1A8 - 15`) it creates one projectile through
`FUN_004E8DF0(0)` and sets `+0x1AC = 40`. At the deadline it fires one or two
projectiles via `FUN_004E8DF0(1)` + `FUN_00544130(x +-0x46/+-0x4E, y - 0x18,
target, 1)` (second ball at `y - 0x10`), sound `0x143`, then
`+0x1A4 = 0`, `+0x1A8 = rand()%50 + 150` (300 in demo).

`FUN_004E8DF0` scans `Tank+0x108` and returns the *farthest* eligible object
(types 5-0xA unconditional, type 0 gated by `FUN_00500FF0`, types 0x14/0x15
gated on a live boss); no eligible target means no shot. It also clears the
byte at the alien's `+0x190`.

### 8.3 Psychosquid (kind 7) - sleep cycle

`+0x194` counts to `+0x198` (400) while `manager+0x880 == 0`; on overflow it
flips `+0x204`, sets `+0x19C = 1`, `+0x1AC = 10`, and re-seeds
`+0x194 = rand()%100`. Entering rest also sets speed 0.5, plays sound `0x135`
and calls `FUN_00537F90(-1)`; waking sets speed 2.0. While resting the draw uses
rows 4/5 and the alien is harmless (it neither eats nor is a salvo shooter).

### 8.4 Cyrax (kind 0x15) - summons and fireballs

> **Corrected in P2.9 (EV-0117, `p2.9-bosses.md` §4).** The two actions below were
> read the wrong way round, and there is no projectile: `FUN_00545580(x, y)`
> spawns a **Minisylvester** (kind 0x14 at the boss + (0x28,0x28)) every 75 ticks,
> and the 300-tick action calls `FUN_005475B0(type, 1)` with `type = rand()%6 + 4`,
> i.e. the **generic wave spawner** for a random alien type 4-9. The section title's
> "fireballs" has no binary counterpart.

- Every `+0x1E8` (75) ticks: `FUN_00545580(x, y)` spawns a boss projectile.
- While both `Tank+0xB8` and `Tank+0xF4` stay empty, `+0x1DC` counts to
  `+0x1E4` (300); then `Tank+0x700 = rand()%6 + 4` (4-9) and
  `FUN_005475B0(count, 1)` summons that many Minisylvesters.
- Cyrax is the only alien whose HP bar always draws, and the only one that
  occupies `Tank+0x110`; the wave clock is frozen while he lives.

### 8.5 Bilaterus (kind 8)

Two heads, one active. Head hp is the head's `+0x1D8` (100.0). While both heads
exist the active head is swapped every 1000 ticks; when the active head's hp
hits 0, `FUN_004FB4C0` removes/swaps it and marks `+0x164`. The body itself has
no `+0x1F0` hp of its own - it dies with the last head. Bones (`FUN_004EDEA0`)
are cosmetic sub-objects that follow the body.

## 9. Death, drops and damage

`FUN_004F9C70(from_shot)` removes an alien (EV-0113). `from_shot` gates the *effects*,
not the removal:

1. detach the `+0x98` target if set (`FUN_004D80E0`);
2. **diamond drop** - when no boss alien is alive (`Tank+0x110 == 0`), `from_shot != 0`
   and `FUN_004D70B0()` passes, call `Tank::SpawnCoin`
   `FUN_00544430(x+0x19, y+0x19, 4, 0, -1.0, 0)`. Coin kind 4 = **Diamond, value
   200** (EV-0047), and the branch is not kind-gated, so *every* alien killed by a
   shot drops it - Gus and Minisylvester included. `FUN_004D70B0()` is the mode-5
   spawn gate (returns 1 outside VT), so the drop is allowed in every mode;
3. base cleanup `FUN_004DB250()` + `FUN_00539C90()` - runs even when `from_shot == 0`;
4. when `from_shot == 0` jump straight to the unregister (no debris, no anim call);
5. **Gus (kind 4)**: `(rand&1)+2` = 2-3 iterations of two `FUN_00538AC0` particles at
   `(rand%70+30, rand%70+30)` and `(rand%50+50, rand%50+50)`; then `rand%3+4` = 4-6
   iterations of two `FUN_005436F0(x, y, size)` debris chunks with `size = rand%3+3`
   (3-5) at `(rand%50+20, …)` / `(rand%30+40, …)`; then `(rand&1)+2` = 2-3 iterations
   of two chunks with `size = (rand&1)+6` (6-7); sounds `0x11D`/`0x11E`; unregister
   and **return** - Gus never reaches the anim call;
6. **Minisylvester (0x14)**: the same three loops with the small-field offsets
   (`rand%35`, `rand%25+10`, `rand%15+10`), a single sound `0x11F`, unregister,
   return;
7. **every other kind**: 0-1 particle iterations, `rand%3` = 0-2 debris iterations of
   size 3-5, 0-1 iterations of size 6-7, sounds `0x11D`/`0x11E`, then
   `FUN_005442C0(lookup2, lookup1, frame, kind, facing)` with `frame = +0x1C0`,
   `kind = +0x1EC`, `facing = (0.0 < +0x170)` and `lookup1`/`lookup2` =
   `FUN_00564160(frame, kind, facing)` / `FUN_00564160(lookup1)`; unregister. This is
   **not** a money drop - the coin was already spawned in step 2; the pair of resource
   lookups on (frame, kind, facing) points at a death animation/corpse object, so the
   call is left as an open item (Q-0020);
8. `FUN_004F9950()` unregisters the object; every path reaches it.

Corpses (`DeadAlien`) are a separate object; "alien corpses fall to the floor"
is P2.4/P2.5 material, not part of this function.

Damage sources: pet melee `FUN_004FB5B0` (P2.7/EV-0106 -
`Alien+0x1F0` and `Alien+0x1EC` are its inputs, Itchy 1.0 -> 0.25 vs kinds
4/5, Gash 3.0 -> 0.5; every other kind takes the full values) and the player laser,
which is `Alien::HitTest` `FUN_004FA6F0` (P2.9/EV-0120: box test, 10-tick cooldown,
`hp -= 3*Tank+0x3E4`, knockback). Kills route to `FUN_004F9C70(1)`.

Draw-time feedback (`FUN_004DAE20`): kind 4 flashes white only while no boss
alien exists; kind 5 flashes with alpha `(min(+0x1AC, 10-+0x1AC) * 0xFF)/5`
during its salvo; kind 7 switches to the rest rows while `+0x204` is set.
A boss HP bar is drawn for Cyrax and, when `Tank+0x178 != 0` and the tank index
is not 5, for the regular aliens as well.

## 10. Wiki vs binary, unknowns, bounded negatives

Agreements (EV-0114): composite pairs match the multi-alien levels; Destructor's
three homing missiles; Ulysses' two energy balls; Psychosquid's periodic
docile phase; Bilaterus' two heads at 17 hits each with 100 hp; Gus eating
pellets instead of fish; Cyrax summoning Minisylvesters; the ~7.7 s warning
before a wave (276 ticks). P2.9 qualified the Cyrax row: the summon is real but the
"fireballs" are a random alien type 4-9 spawn (`p2.9-bosses.md` §9).

Open (Q-0020):

- kinds 1 vs 2 (one image, hp 50/60, speed 2.0/1.6) - no name in the binary.
- `FUN_004E3ED0`/`FUN_004E3F00`/`FUN_004E3F30`/`FUN_004E3F60` - the four sub-predicates of the
  attack gate `FUN_005392A0`; the three list-emptiness tests of that gate are decoded (EV-0116).
- Alien vtable slot 77 (`consume`) and the victim's slot 75: the class-map dump stops at 64
  entries, so their addresses are unbound (EV-0116).
- Why eating a pellet *costs* Gus hp (`+0x1F0` -4..-30): the pellet helper and pet melee drain
  the same field, so "damage" vs. "a fullness pool that doubles as hp" cannot be settled from
  static code (EV-0116).
- `FUN_005442C0` - the death-animation call of the default branch (§9 step 7); candidate
  corpse/explosion object keyed on (frame, kind, facing), not decompiled.
- `Tank+0x178` (HP-bar flag), `Tank+0x4F4`, `Tank+0x4FE`, `Tank+0x4DE` writers.
- `FUN_004FB1C0` (head swap) exact effects; `FUN_004DAA00` (post-update
  animation/cleanup); slot 0xA4's two-argument meaning.
- kind 0's runtime consequence, see below.
- 4320-tick VT retreat depends on the unwritten `+0x28` age field.

Bounded negatives:

- No `Sylvester`/`Balrog`/`Gus`/`Destructor`/`Ulysses`/`Psychosquid`/`Cyrax`
  RTTI classes exist in the module (P2.2 class map + this task's ctor trace);
  the names are wiki-side only.
- The wave block contains no `Tank+0x2BC == 0` early-out; type 0 reaches
  `FUN_00545620`. A kind-0 alien is therefore constructed but has no stat
  branch, no sprite case and no `+0x1F0` initialisation - it is invisible and
  its hp field is whatever the base object left there. Do not model a "kind 0
  alien"; model tank1 L1 as "no alien this level" (the tutorial text
  "On this level you will meet your 1st alien opponent!" is what the level-1
  code shows) until the countdown guard for type 0 is found.
- `FUN_00543F40` (the 30-tick warning) and `FUN_0054B1A0` (the 1-tick event)
  were not decompiled; only their call sites are proven.

## 11. Implementation spec for P4

1. **One alien entity + kind table.** Implement a single `Alien` node with a
   `kind` field and a `kind -> AlienDef` resource (hp, speed divisor, box size,
   sprite, frame rows, warning sound, attack model, death profile). Do not
   create one class per species; the original does not.
2. **Separate Bilaterus.** `Bilaterus` is a distinct entity that owns 2
   `BilaterusHead` children (80x80, 100 hp each) and 6 cosmetic bones. Model the
   head as an entity so pets can target it; the body has no HP of its own.
3. **Kind table (value -> use).** 1/2 Sylvester (`hp 50/60`, `speed 2.0/1.6`),
   3 Balrog (130, 1.2), 4 Gus (100, 1.6, eats pellets), 5 Destructor (150, 1.2,
   bottom lane, 3 missiles), 6 Ulysses (220, 3.5, bottom lane, 2 balls),
   7 Psychosquid (260, 0.5/2.0, rest cycle), 8 Bilaterus, 0x14 Minisylvester
   (1 hp, 80x80, 0.8-1.2), 0x15 Cyrax (2500-5000 by defeat count).
   Kinds 9-0xC are *spawn recipes* (1+3, 7+3, 5+6, 3+8), not entities.
4. **Selection vs instance.** Keep `Tank.alien_type` (spawn selection) and
   `Alien.kind` (instance) as separate fields exactly like `Tank+0x2BC` /
   `Alien+0x1EC`; composite types must spawn two entities without changing the
   stored type.
5. **Wave clock.** 3000-tick countdown at 36 Hz with the pause contract: the
   clock only ticks when `alien_type != 0`, no boss is alive, and the
   alien/projectile lists are empty. Fire the 276 (message), 275 (warp-hole +
   coordinate roll), 33 (sound), 30 (warning), 1 (event) and 0 (spawn) steps in
   that order, then set 3000 again.
6. **Spawn coordinates.** Keep both rolled points (`x = rand%450 + 20`,
   `y = rand%195 + 105`) and use the second pair for the second member of a
   composite. Do not randomise per entity.
7. **Type re-roll.** Reimplement §5.1 verbatim, including the 40/40/20 split on
   tank4 L5 and the challenge substitutions (`0xC` after wave 4). Keep the demo
   pools behind a debug flag only.
8. **Movement.** Clamp bands (x -10..490, y 85..290; mini 10..540 / 95..370),
   `position += velocity / speed`, quadrant wander with 0.1 steering steps and
   the 20-tick / 10 % re-roll, `+-3` intro drift for the first 7 ticks.
9. **Attack models.** Data-drive them: `none` (Sylvester/Balrog/Gus/mini),
   `missiles_3` (Destructor: offsets +-90/105/120 and -10/-25/-40 at y -35/-30/
   -25, sound 0x128, period 75 then `rand%50+150`), `balls_2` (Ulysses: one ball
   15 ticks early, two at the deadline, sound 0x143, same period), `rest_cycle`
   (Psychosquid: 400-tick cycle, rest = docile + sound 0x135), `boss` (Cyrax:
   projectile every 75 ticks, summon 4-9 minis after 300 clear ticks), `heads`
   (Bilaterus).
10. **Eating.** Two steps per tick, both gated by `attack_gate() && kind not in
    {5,6} && not resting`: (a) select the nearest eligible target (pellet list for
    Gus, creature list for everyone else), (b) steer toward it - 0.1/tick with a
    1.8 cap, Gus-on-pellet 0.3/tick with a 3.0 vertical cap - and run the bite: a
    centre-to-centre reach test of +-45 x / +-65 y (mini +-30, target type 6
    +-70/+-85) that hands off to the alien's `consume` and the victim's `get_eaten`
    virtual. Eating is a chase, not an instant consume; a flashing non-Gus alien
    cannot bite. Gus also consumes pellets, each costing him 4-30 hp - read Q-0020
    before shipping that number.
11. **Death.** One `alien_die(from_shot)` path: a kind-independent Diamond drop
    (`spawn_coin(kind 4)`, value 200, suppressed while the boss is alive and only
    when `from_shot`), then per-kind effects - Gus 2-3+4-6+2-3, mini the same with
    small offsets and one sound, default 0-1/0-2/0-1 - sounds 0x11D/0x11E (0x11F
    mini), a death-animation call for the default kinds only, then unregister.
    `from_shot == 0` skips every effect.
12. **Boss level.** Cyrax sets `pet_capacity = 10` and freezes the wave clock;
    his HP scales with `profile+0x54` (defeat counter, incremented when more
    than 1000 damage is dealt). His HP bar is always visible; regular alien HP
    bars only appear when the tank's bar flag is set and the tank is not 5.
13. **Open-item guards.** Keep the attack gate, the eat operation, the
    `Tank+0x178/0x4F4/0x4FE` flags and kind 0 behind named config values with
    the wiki-safe default (no attack during the intro, no kind-0 spawn), and
    note them in `docs/SPECS.md` at P2.18.
