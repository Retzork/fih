- 12-item arrays: `A +0x2E4` (slot, -1 = hidden), `B +0x314` (price), `C +0x344` (base),
  `D +0x374` (mode-4 increment); item-present bytes `+0x3A4+i`.
- Adventure (mode 0): `+0x3C8` tank = `profile+0x1C`, `+0x3CC` level = `profile+0x20`
  (other modes: tank = `manager+0x888`, level = 5).
- `+0x3F0` money: 999999 (mode 3 / Sandbox), 200 otherwise (demo: 200, `+0x3E4` = 8).
- `+0x43C = 1` egg pieces; `+0x3E4 = 2` pet slots; `+0x4AC = 5`; `+0x2C0 = 3000`.
- Defaults derived in the final loop: `C[i] = B[i]`, `D[i] = B[i]/100` when `D[i] == -1`;
  `+0x2DC` = count of items with `A[i] >= 0`.
- `FUN_00537C20()` called at the end of `FUN_00541200` (role still open).
