## 2. Entity model

### 2.1 Classes, vtables, and shared fields

Two classes implement all 24 pets. EV-0078.

- `Sexy::OtherTypePet`, vtable `0x596D74`, used by `{0,1,5,7,0xE}`.
  Its vtable ends at slot 80 (`0x4D8AD0`, destructor); it has no 81+ overrides.
- `Sexy::FishTypePet`, vtable `0x597EC4`, used by every other pet.

Both derive from the common tank-object base (`+0x10` vtable-ish object ref,
`+0x30/+0x34` screen x/y, `+0x38/+0x3C` width/height, `+0x88` manager,
`+0x8C` type id, `+0xF4` alive/active byte).

### 2.2 Creation and session loading

`FUN_00544A90(index, x, y, transformed, ???)` is the single pet spawn helper
(EV-0079). It picks the class from the index set above. When `x == -1` it
randomizes x in 105..369 and y in 20..539. In mode 5 it writes
`obj+0xAC = 1000 + (transformed ? 0x13 : index)`, which is the Virtual Tank
persistence/ID value. Index 0x13 forces the Presto flag.

`FUN_005498B0` (session init) has two pet branches (EV-0079):

- branch A: for `i = 0..0x12`, spawn pet `i` when `FUN_00501410(i)` (owned flag)
  is set;
- branch B: for `i = 0..0x17`, spawn the selected profile entry
  `profile+0x5A+i`.

The branch choice depends on `profile+0x18 < 4` and mode/`profile+0x59`; the
exact meaning of `profile+0x18` remains open (Q-0013 area). The spawn helper does
not enforce a per-level pet count; capacity is a profile/UI decision.

## 3. Shared AI framework

### 3.1 Update order and gates

`FUN_004F2E80` (OtherTypePet) and `FUN_004F7AD0` (FishTypePet) are the two
per-frame updates (EV-0080). Common gates:

- `Tank+0x94 != 0` pauses pet actions (used by screens/overlays).
- tank index `Tank+0x3C8 == 5` disables the slot-81 action tick (tank 5 boss).
- slot 81 is skipped while hostile aliens are present, except Stanley (0x16).
  This is why Prego stops birthing and most timers freeze during an invasion.
- `FUN_004E9790` is the action gate used by slot 82; it distinguishes normal
  play, alien presence, and Virtual Tank.

`FUN_004E5900` (slot 81) is the per-pet timer/action dispatcher (EV-0080). It
returns early on tank 5 or `Tank+0x94`, then switches on the pet index. The
branches observed there are the authoritative timer semantics for Prego (3),
Zorf (4), Vert (6), Meryl (8), Shrapnel (0xB), Amp (0x10), Gash (0x11),
Nostradamus (0x15), and Stanley (0x16). Other pets act through
`FUN_004FE740`/targeting instead.

`FUN_004E02D0` (slot 84) steers toward a target with class-specific speed and
x/y clamps. `FUN_004E5FC0` (slot 85) selects the target; its branches cover
coins, aliens, corpses, and projectiles. `FUN_004FE740` (slot 86) resolves
contact damage/collection. `FUN_004F8610` (slot 83) renders the pet and its
per-pet overlays.

### 3.2 Tick rate

All pet timers are raw update ticks, not seconds. The best independent anchor is
Blip: the binary compares the level age against `200` and `720` for the normal
and Presto-transformed instant-unlock, while the wiki gives 5 s and 20 s
(EV-0094). `200/5 = 40`, `720/20 = 36`; combined with Prego 930 ticks ≈ 26 s,
Meryl 1400 ≈ 39 s, and Shrapnel 633..652 ≈ 18 s, 36 Hz is the working rate
(EV-0080/EV-0105). Timers below are therefore quoted in ticks and, where useful,
in seconds at 36 Hz. This is consistent with the P2.1 frame-loop work; do not
convert to seconds in the simulation layer.

### 3.3 Presto transformation

`FUN_004F89A0(targetIndex)` performs the transform (EV-0100):

1. ignore if `targetIndex == +0x234`;
2. `FUN_004F2650(+0x238)` must return true. That helper returns true when the
   timer is `< 1`; otherwise it draws "Recharging..." at
   `(x + width/2 - 20, y - 10)` and returns false;
3. play sound `0x122`, spawn the target with `FUN_00544A90(target, x, y, 1, 0)`,
   remove the old object, and call `FUN_004D6250` (cleanup);
4. when swapping Walter (0x17) and Presto (0x13), copy `+0x264` and `+0x260`
   so Walter's punch state survives the transformation.

`FUN_004D6250` (EV-0100) decrements `DAT_005e89d0` if a hidden Wadsworth (index 9)
is removed, and clears `DAT_005e89cc` if Meryl (index 8) is removed. This is why
transforming away a hidden Wadsworth or an active Meryl must run the same
cleanup as selling/removing the pet.

`FUN_0054C6F0` opens the "PRESTO CHANGE-O" picker (EV-0100). It allocates a
`Sexy::PetDialog` (0x2F8 bytes) via `FUN_005355C0` and pushes screen id `0x1F`;
the dialog exposes the 24 owned-pet slots. It is not a sell path.

## 4. Per-pet behavior

Each section records what the binary proves, then the wiki comparison and the
remaining unknowns. "Wiki" statements are context only (D-0010); the binary
remains the proof.

### 4.1 Stinky (0x00) - EV-0081

- `OtherTypePet`; ctor forces `y = 370.0` and speed 1.2, so he moves on a fixed
  bottom lane and only `vx` steers. This is a lane, not a hard bottom clamp.
- `FUN_004EBC80`/`FUN_004E7270` chase the nearest collectible coin. Exclusions:
  kinds 3 and 10 when the Penta list `Tank+0xD0` is non-empty; kind 0x11
  (bomb); kind 0x12 (snot); coins already claimed/reserved via coin `+0x198`.
- `FUN_004E2A20` index 0 maintains the hide counter `+0x1B4`: while
  `Tank+0xB8` or `Tank+0xF4` is non-empty it increments up to 9 and zeroes
  `+0x1BC`; when both are empty it decrements to 0. The render uses the counter
  for the shell/hidden frames. Coins touching him while hidden are not
  collected.
- Wiki: random target choice (binary proves nearest, not random); a collection
  cooldown (binary has `+0x1BC` gating, exact cooldown not isolated); ignores
  stars once a Starcatcher exists (binary: kind 3/10 exclusion when Penta list is
  non-empty, and the exclusion persists); hides during aliens (matches); turns
  red after 20 s of failed chasing with Nimbus (cosmetic path not found; EV-0106).
- VT: the generic sleep test is `Tank+0x28 - Tank+0xF0 < 0x1950` with a
  `%0x3C` random branch (`FUN_004D6B70`); it is not Stinky-specific and the
  "3 minutes" figure is not proven. Do not hard-code 180 s from the wiki.

### 4.2 Niko (0x01) - EV-0082

- `OtherTypePet`; no fixed perch: spawn uses the generic random x/y and the
  generic wander code. The wiki "stationary on a pillar" is not in the spawn or
  update path (EV-0105 open discrepancy).
- `FUN_004E2A20` index 1 runs only when `Tank+0x3C8 != 5` (not the tank-5 boss).
  It increments `+0x1B4` every tick:
  - `0x4C8` (1224 ticks ≈ 34 s): sound `0x129`;
  - `0x4D1` (1233): spawn pearl coin kind `0xF` at `(x+1, y-2)`, clear
    `+0x1C0`, sparkle at `(x+0xB, y+5)` and `(x+7, y+3)`;
  - `0x5A0` (1440 ticks = 40 s): sound `0x12A`;
  - `0x5AA` (1450): close, reset `+0x1B4 = rand % 0x32` (0..49), so the next
    cycle is 1224..1273 ticks.
- `FUN_004E2BD0` renders the open/closed frames from `+0x1B4`; the pearl-taken
  flag `+0x1C0` selects the "empty" frame.
- Wiki: first pearl 34 s, subsequent 40 s (matches 1224/1440 at 36 Hz); pearl
  value $250 (coin kind 0xF; value in P2.5); cannot be collected by money pets
  (the pearl is a clickable coin, and Stinky/Clyde exclude kind 0xF); VT value
  10 shells. Presto-as-Niko falls to the bottom and ignores the perch (matches
  the absence of perch code, but the fall itself was not traced).

### 4.3 Itchy (0x02) - EV-0083

- `FishTypePet`; default ctor tuning. `FUN_004E5FC0` selects the nearest hostile
  in `Tank+0xF4` and `Tank+0xB8`.
- `FUN_004FE740`/`FUN_004FB5B0` index 2 deals `1.0` damage (0.25 against alien
  class `+0x1EC` 4 or 5), plays sound `0xB`. He does not intercept projectiles.
- Wiki: attacks about once per 0.25 s, level-1-laser damage, does not attack
  resting Psychosquid or missiles/energy balls. The damage number matches; the
  exact 0.25 s cadence was not isolated in slot 86 (the generic contact tick is
  the likely gate). Treat cadence as an implementation parameter until P2.8.

### 4.4 Prego (0x03) - EV-0084

- `FishTypePet`; ctor `+0x224 = 0x3A2` (930), `+0x190 = 360`.
- Slot 81 increments `+0x220`. In VT, at `threshold - 0xD2` (210) it samples
  fish counts and rewinds the timer by 300 if the population condition is not
  met. At the threshold it resets `+0x220 = 0`, spawns a guppy with
  `FUN_00546EF0(x+7, y+25)`, sets the VT guppy field `+0x120 = 0x28` in mode 5,
  plays sound `0`, then chooses the next threshold:
  - `Tank+0xA0` fish count > 10 -> `2000`;
  - otherwise `930 + (rand > 5 ? 300 : 0)`, i.e. 930 or 1230.
- Wiki: about every 26 s, belly swells shortly before birth, timer pauses during
  alien invasions. 930/36 = 25.8 s; the slot-81 skip during aliens matches the
  pause. The 2000-tick crowded case and the 930/1230 split are binary-only.
- Unknown: the exact VT population test (`FUN_0053A3C0`/`FUN_005397A0`) and the
  belly-swell thresholds. Keep the timer and the 2000 fallback; expose the VT
  gate as a callback.

### 4.5 Zorf (0x04) - EV-0085

- `FishTypePet`; ctor `+0x224 = 65`, speed 3.0, `+0x190 = 270`.
- Slot 81: if `Tank+0x194 == 0`, it only acts when a fish with `+0x9C < 300`
  (hungry) and `+0xF0 == 0` exists. If `Tank+0x194 != 0`, it increments
  `+0x240` and acts every 2 ticks normal / 4 ticks VT even without a hungry fish.
  On acting it sets `+0x220 = -10` and spawns food kind 1 or 2 with
  `FUN_00543280(x+15, y+10, kind)` depending on `vx` sign.
- Wiki: level-2 food every 2 s, does not count against the food limit, cannot be
  upgraded to level 3, feeds Brinkley. 65 ticks = 1.8 s.
- `Tank+0x194` is an unidentified cached tank value. Do **not** label it a
  Brinkley count (EV-0107). The food kind 1/2 mapping to levels must be checked
  in P2.3/P2.5 before use.

### 4.6 Clyde (0x05) - EV-0086

- `OtherTypePet`; speed 1.5, no fixed y. `FUN_004EB7C0` index 5 advances the
  direction animation every `0x13` (19) frames; `FUN_004E02D0` does 2D steering
  with ±1.0 target vx.
- Collects the same coin set as Stinky (kinds 3/10 only when Penta exists,
  excludes 0x11/0x12/claimed), plus a `FUN_004E4F90` check. He does not hide
  during aliens and remains active.
- Wiki: faster than Stinky, not bottom-bound, remains active during alien
  attacks, slides when a coin is stolen or missed, ignores stars after a
  Starcatcher is bought (binary same Penta condition), VT sleep after 3 minutes
  (generic sleep test only).

### 4.7 Vert (0x06) - EV-0087

- `FishTypePet`; ctor `+0x224 = 216` normal, `1080..1279` VT.
- Slot 81 increments `+0x220`; at the threshold it calls `FUN_004D70B0` and, if
  allowed, spawns coin kind `2` at `(x+15, y+10)`. It does not require food.
- 216 ticks = exactly 6.0 s; wiki 6 s matches. Wiki VT drops gold shells (kind 2
  with the VT multiplier).
- `FUN_004D70B0` returns 1 in normal play, and in VT only when the avatar screen
  is not in a blocked state; this is the same gate used by other mode-5 spawns
  (EV-0107).

### 4.8 Rufus (0x07) - EV-0088

- `OtherTypePet`; ctor forces `y = 365.0`; steering caps x at 560 and uses speed
  1.8. He is a bottom lane attacker.
- `FUN_004E5FC0` selects the nearest hostile in `Tank+0xF4`/`Tank+0xB8`;
  `FUN_004FE740` deals `2.0` (0.5 against alien class 4/5/6). Contact requires
  the target to be in the bottom region; the exact y threshold was not isolated.
- Wiki: heavy damage (level-6-laser equivalent), attacks enemies lured to the
  bottom, strong against Destructor/Ulysses. Damage and bottom lane match; the
  per-alien resist table is P2.8 work.

### 4.9 Meryl (0x08) - EV-0089

- `FishTypePet`; ctor `+0x224 = 1400` normal, `4320` VT.
- Slot 81 increments `+0x220`:
  - at `threshold - 100` (1300) it sets `DAT_005e89cc = 1`, spawns coin kind
    `0x10` at `(x+15, y-5)`, plays sound `0x137`;
  - at the threshold it clears `DAT_005e89cc = 0` and resets `+0x220 = 0`.
- Kind `0x10` has value 0 in the coin table; it is a song/note marker, not the
  money. The actual "guppies drop three coins" effect is the fish reaction to
  the song (inference; the reaction body was not decompiled in this pass). The
  global `DAT_005e89cc` is the song-active flag.
- Wiki: every 40 s (1400/36 = 38.9 s), VT every 2 min (4320/36 = 120 s);
  non-guppies unaffected. The timer and marker match; the guppy reaction and
  the exact "three coins" rule remain P2.3/P2.7 follow-up.

### 4.10 Wadsworth (0x09) - EV-0090

- `FishTypePet`; ctor `+0x224 = 120`, speed 4.0.
- Hide state is `+0x250`; when hidden he increments the global hidden count
  `DAT_005e89d0` and stores his mouth position in `DAT_005e89D4/+0xD8`.
  Predicates `FUN_004E7010`, `FUN_004E7130`, `FUN_004E3EA0` decide which fish are
  eligible; `FUN_004E9790` gates the action during aliens.
- `FUN_004D6250` decrements `DAT_005e89d0` when a hidden Wadsworth is removed
  (transform-away included), clamping at 0.
- Wiki: shelters small and medium guppies; Challenge Mode puts him to sleep if
  all unprotected fish die. The shelter flag/count/position are proven; the
  size filter and Challenge sleep are not (EV-0106).

### 4.11 Seymour (0x0A) - EV-0091

- `FishTypePet`; no ctor branch. The only proven effect is `Tank+0x16C`:
  coin fall speed 1.5 -> 0.8 and coin expiry `0x14` -> `0x82` while the field is
  set. The writer of `Tank+0x16C` was not found; do not assert an aura radius or
  a stacking rule.
- Wiki: slows falling money/shells and their disappearance. The field effect
  matches both claims; the trigger/writer remains open (EV-0106).

### 4.12 Shrapnel (0x0B) - EV-0092

- `FishTypePet`; ctor `+0x224 = 633..652` normal, `1080..1279` VT.

## 5. Cross-pet rules

- **Alien gating:** slot 81 is skipped while hostile aliens are present for
  every pet except Stanley; Stinky hides, Prego pauses, and most timers freeze.
  The gate is `Tank+0x94` plus the alien-list presence test in `FUN_004E9790`.
- **Coin kinds:** 3/10 are star kinds (excluded when Penta/Starcatcher exists),
  0x11 is Shrapnel's bomb, 0x12 is snot, 0x10 is Meryl's song marker, 0xF is
  Niko's pearl. Collectors must use the per-pet exclusion sets, not a single
  global "collectible" flag.
- **VT sleep:** `+0x1B0` (OtherTypePet) and `+0x245` (Nimbus) are movement
  divisors, not despawn flags. The generic sleep test is the `FUN_004D6B70`
  timer; the wiki's "3 minutes" is not proven.
- **Removal:** always run `FUN_004D6250` when a pet is removed/transformed. It
  maintains `DAT_005e89d0` (hidden Wadsworth count) and `DAT_005e89cc` (Meryl
  song flag).
- **Presto:** the transformed object is a real pet of the target index with
  `+0x230`/`+0x1C8` set; it inherits the target's timers. The recharge is on the
  Presto object (`+0x238`), not on the target.

## 7. Implementation spec for P4

1. **Data model.** One `PetDef` resource per index 0..23 with: `id`, display
   name, class (`other`/`fish`), speed, fixed-y (or null), action period in
   ticks, secondary timers, coin-kind rules, and a behavior script key. Keep
   999 out of `PetDef`; it is a card/UI definition only.
2. **Simulation rate.** Run pets at the tank's fixed 36 Hz tick. Store all
   periods as integer ticks (`930`, `1400`, `360`, `216`, `65`, ...). Convert to
   seconds only in UI/tooltips. Do not use `delta`-scaled floats for timers.
3. **Entity split.** Implement `OtherTypePet` (Stinky, Niko, Clyde, Rufus,
   Rhubarb) with the `+0x158..+0x1C8` layout and direct chase/collect updates.
   Implement `FishTypePet` with the `+0x180..+0x264` layout and the 81..89
   dispatch. Both share a base with x/y/width/height/manager/type/alive.
4. **Update gates.** Order: base tick -> pause gate (`Tank+0x94`) -> tank-5
   action skip -> alien gate (skip slot 81 except Stanley) -> slot 81 action ->
   steering/targeting -> contact/attack -> render. Stinky's hide counter and
   Prego's paused timer are consequences of these gates, not special cases.
5. **Coin rules.** Implement per-pet predicate functions over the coin kind and
   claim flag; do not centralize as "collectible". Required exclusions:
   Stinky/Clyde kinds 3/10 when Penta exists, 0x11, 0x12, claimed; Nimbus
   kind<8 -> +7 and excludes 0x11/3/10/0x12; Niko pearl kind 0xF is clickable,
   not collector-valid.
6. **Timers.** Reproduce the exact slot-81 branches: Prego 930/1230/2000;
   Zorf 65 + 2/4 cadence; Vert 216; Meryl 1400/4320 with the marker at
   threshold-100; Shrapnel 633..652; Nostradamus 300..599/1080..1279; Amp 3000;
   Gash 1570/1520; Stanley 100. Keep the random ranges as ranges.
7. **Presto.** Model the transform as: picker -> check `+0x238 < 1` -> spawn
   target at the same x/y with `transformed=true` -> remove old -> run cleanup.
   The target is a normal pet; the only Presto-specific state is the recharge
   and the label. Preserve `+0x260/+0x264` when swapping Walter/Presto.
8. **Walter.** Implement the glove as a separate short-lived entity (life 30,
   direction, 0xA0x50 hitbox, hit list `Tank+0x108`). On hit apply
   `+0x20C=50`, `+0x210=180`, `+0x220=+0x224-type`, knockback ±15/±10, sound 3,
   and let the target's own action code react. Five punches then sleep is a
   configurable counter until its writer is found.
9. **Angie.** Target only corpses with `+0x1A0 > 0x5F`; on contact set
   `+0x190 = 10` if it was 100. Do not revive fish that were eaten without a
   corpse.
10. **Open-item guards.** Put the unresolved items behind explicit config flags
    with wiki defaults disabled: Gumbo fish lure, Blip overlays, Seymour aura,
    Amp click/electrocution, Nostradamus sneeze/clones, Wadsworth challenge
    sleep, Brinkley 12/36/108 vs 15/45/135. The remake must not silently ship a
    guessed mechanic.
11. **VT.** Use the same pet entities; mode 5 changes periods (Vert/Meryl/
    Nostradamus/Shrapnel), the VT gate `FUN_004D70B0`, and the coin-to-shell
    conversion. The wiki's "3 minutes" sleep is not implemented until the
    generic sleep test is bound.
12. **Removal/cleanup.** Every despawn, sell, transform, or level teardown calls
    `PetCleanup` (the `FUN_004D6250` equivalent): hidden Wadsworth count--,
    Meryl song flag clear, glove detach. This prevents cross-level state leaks.
