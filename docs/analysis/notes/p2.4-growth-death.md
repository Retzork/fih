## 2. Common ctor tuning (`FUN_004DE370`, defaults for every fish)

- Position `+0x158`/`+0x160` (dbl) = x/y args; ints `+0x30`/`+0x34` via `FUN_00564160` (x87 round).
- `vy +0x170 = -0.5`; sprite box `+0x38`/`+0x3C` = 0x50 (80x80 - matches P4 asset contract).
- Facing: 50% `vx +0x168 = -0.1`, scale `+0x188 = -1.0` (flip); else 0 / 1.0.
- Bounds: `+0x190 = 370`, `+0x194 = 10`, `+0x198 = 95`, `+0x19C = 540`.
- Speed divider `+0x180` = rand%3 of {2.0, 1.8, 1.6} (three individual speed classes).
- **Hunger `+0x9C = rand%200 + 400`** (starts 400-599). Food points `+0x1A4 = 0`.
- **Growth threshold `+0x1A8`: mode 5 -> rand%9 + 12 (12-20); normal -> rand%3 + 4 (4-6)**.
- Timers: `+0x1B0 = 0x28` (40), `+0x1AC = rand%10` (dir), all anim/effect fields zeroed.
- **Coin timer `+0x224 = FUN_004D71D0(rand%200 + 0x96 (150))`** (initial next-coin threshold;
  `FUN_004D71D0` role open - ramping helper). Also `+0x1A0..+0x1D4` zeroed, `+0x229 = 1`.
- `+0x228` = `FUN_00537B80()` (tutorial/help flag) when a tank exists; byte `+0x55 = 1`
  (0 when tank food lists `+0xB8`/`+0xF4` non-empty). `+0x208/+0x20C/+0x210/[0x218] = 0`.

## 3. Tier init (Oscar, `FUN_004D84C0` after guppy ctor)

- `[0x8C] = 5`, **stage `+0x1A0 = 5`** (carnivores are born at stage 5).
- `+0x229 = 0`; `+0x198 = 0x69 (105)` (top bound); `+0x190 = 0x168 (360)`.
- **Hunger `+0x9C = rand%200 + 600`** (600-799). Byte `+0x55 = DAT_005e8f14` (global).
- Demo (`[manager+0x880]`): calls slot 90 with `rand%12 + 0x1E (30)` and sets byte `+0x1D0 = 1`.
- Stage numbering: Guppy 0..4 (0->1->2->3 growth; 4 = post-star), Carnivore 5..7,
  Ultravore 8..9 (all via the same `[0x1A4]` points vs `[0x1A8]` threshold machine, P2.3 §7).

## 4. Starvation and death

- Same hunger machine as Guppy (P2.3 §6): `[0x9C] < -499` -> slot 88 `0x4D5F90` (die).
- `DeadFish` class (slots 22/26 = `0x4F64E0`/`0x4DE030` per the EV-0043 vtable map) replaces
  the fish; its Update `FUN_004F64E0`:
  - Gates: tank `[manager+0x730]` exists and not paused (`tank+0x94`); `FUN_004F22C0()`.
  - Death anim phase `[+0x190]` int (99/100 = `+0x18C`/`+0x190` reused as ints): if 1..10 ->
    decrement, `[+0x18C]` = phase (frames 7/8/9 by phase); if >10 or <0 -> frames by
    species id `[+0x1A4]` (hmm: the `[0x69]` reads - same slots reused).
  - At phase < 1: **`FUN_00538230(0x125, 3, 1.0)` = death sound 0x125**, then slot 81 call and
    **spawn-by-id `[0x69]`** (`+0x1A4`): 5 -> `FUN_00544D80(x,y,facing)`,
    6 -> `FUN_00544FE0`, 7 -> `FUN_005451C0`, 8 -> `FUN_00545360`, 9 -> `FUN_005454F0`,
    10..12 -> `FUN_00547270(x, y, id-10, facing)`, else -> `FUN_00546FC0(x, y, id, facing)`.
    (These are the "float away" reward/corpse spawns per species/pet.)
  - Corpse physics: drifts up (vy ramp to 2.0, x ramps to -1.5 when `+0x188`?), x drifts
    `-0.02`/tick while `[+0x1A0] < 0x69`; clamps x 10..540, y 85..(370/380, 310 for
    6, 370 for 8/9); position commit via slot 41.
  - High id range (`[0x69] >= 0x65`): frame = `9 - (id - 0x6A)/2`; ids `0x65/0x66 -> 7`,
    `0x67/0x68 -> 8`, `0x69 -> 9` (pet corpses - pets can die too).

## 8. Implementation spec for P4 (growth/death)

1. Fish entity: species + stage fields; stage ranges Guppy 0-4, Carnivore 5-7, Ultra 8-9
   (+ other species per their init helpers - decode before implementing those tanks).
2. Spawn defaults from `FUN_004DE370`: sizes 80x80, bounds (10..540 x, 95..370 y),
   vertical drift -0.5, speed class {2.0, 1.8, 1.6}, initial hunger 400-599 (Oscar 600-799),
   growth threshold 4-6 points (mode 5: 12-20), random initial facing/direction.
3. Growth: feed points `+0x1A4` vs `+0x1A8`; stage-up restarts points, plays grow anim
   (`+0x1CC = 10`); overshoot (mode 5 ? 8 : 15) x threshold -> stage 4 (diminutive/flash).
4. Feeding: accept only normal pellets (variant 0) or breeding pellets pre-stage-3, otherwise
   per-diet; nutrition per quality/species; star-potion specials (death/stage 3).
5. Death: hunger < -499 -> die() -> spawn reward object by species id, death sound 0x125,
   corpse floats up with drift, despawns.
6. Presentation: bounce/wobble from Update (P2.3 §5), flash alpha on hit (`+0xA0`),
   corpse phases 7/8/9, splat particles for predation when gore option on.
