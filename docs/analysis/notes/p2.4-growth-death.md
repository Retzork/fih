## 2. Common ctor tuning (`FUN_004DE370`, defaults for every fish)

- Position `+0x158`/`+0x160` (dbl) = x/y args; ints `+0x30`/`+0x34` via `FUN_00564160` (x87 round).
- `vy +0x170 = -0.5`; sprite box `+0x38`/`+0x3C` = 0x50 (80x80 - matches P4 asset contract).
- Facing: 50% `vx +0x168 = -0.1`, scale `+0x188 = -1.0` (flip); else 0 / 1.0.
- Bounds: `+0x190 = 370`, `+0x194 = 10`, `+0x198 = 95`, `+0x19C = 540`.
- Speed divider `+0x180` = rand%3 of {2.0, 1.8, 1.6} (three individual speed classes).
- **Hunger `+0x9C = rand%200 + 400`** (starts 400-599). Food points `+0x1A4 = 0`.
- **Growth threshold `+0x1A8`: mode 5 -> rand%9 + 12 (12-20); normal -> rand%3 + 4 (4-6)**.
- Timers: `+0x1B0 = 0x28` (40), `+0x1AC = rand%10` (dir), all anim/effect fields zeroed.
- **Coin-pacing value `+0x224 = FUN_004D71D0(rand%200 + 0x96 (150))`** (inferred next-coin
  threshold; `FUN_004D71D0` role open - ramping helper). Also `+0x1A4`, `+0x1B0..+0x1D4` zeroed
  (stage `+0x1A0` is set later by the species ctor/arg), `+0x229 = 1`.
- `+0x228` = `FUN_00537B80()` (tutorial/help flag) when a tank exists; byte `+0x55 = 1`
  (0 when tank food lists `+0xB8`/`+0xF4` non-empty). `+0x208/+0x20C/+0x210/[0x218] = 0`.

## 3. Tier init (Oscar, `FUN_004D84C0` after guppy ctor)

## 4. Starvation and death

- Same hunger machine as Guppy (P2.3 §6): `[0x9C] < -499` -> slot 88 `0x4D5F90` (die).
- Corpse spawner `FUN_005441F0(...)` (EV-0052): alloc 0x1A8 -> play ctor `FUN_004EED20`; type
  id `[0x8C] = 0x1B` (resolves the pending factory id 0x1B of EV-0044; bare ctor
  `FUN_004EED00`); activation `FUN_00542EE0(obj, 0)` = **inert** (live objects use flag 1);
  list-add via `[manager+0x10]` vtable +0xC; `+0x94 = parent` (parent's `+0x158` gets the
  corpse back-pointer); UI refresh `FUN_0053AA40()`.
- `DeadFish` class (slots 22/26 = `0x4F64E0`/`0x4DE030` per the EV-0043 vtable map; runs the
  death sequence): Update `FUN_004F64E0` (full replay EV-0053):
  - Gates: tank `[manager+0x730]` exists and not paused (`tank+0x94`); `FUN_004F22C0()`.
  - Death phase counter int at `+0x190` (frame index `+0x18C`; Fish slots reused as ints):
    while 1..10 the counter ticks down and the frame follows. Outside 0..10 the frame comes
    from id `[+0x1A4]` and stage `[+0x1A0]`: id 8/9 -> 9 (or `9 - (stage - 0x6A)/2` when
    stage > 0x69); other ids -> stage 0x65/0x66 -> 7, 0x67/0x68 -> 8, stage > 0x69 ->
    `9 - (stage - 0x6A)/2`, else 6 (stage <= 100) or 9 (stage > 100).
  - Stage `< 1` -> own-vtable slot 0x144 = generic detach `FUN_004DB250` (manager list remove
    + tank vtable `+0x88` + `FUN_00541D90(obj,0)` + parent cleanup `FUN_004D9080`) and return
    (terminal, silent). At phase < 1: **`FUN_00538230(0x125, 3, 1.0)` = death sound 0x125**,
    detach via slot 0x144, then **spawn-by-id `[0x69]`** (`+0x1A4`) at packed `+0x30/+0x34`
    with facing `+0x158`, all thin spawn wrappers around play ctors:
    5 -> `FUN_00544D80(x,y,f)` -> ctor `FUN_004EFE00` (Oscar family) + counter `Tank+0x46C`;
    6 -> `FUN_00544FE0(x,y,f)` -> ctor `FUN_004F0310` (Ultra family);
    7 -> `FUN_005451C0(x,y,f)` -> ctor `FUN_004EFA10` (Gekko family);
    8 -> `FUN_00545360(x)` -> ctor `FUN_004EC080` (Penta; tank list `+0xD0`, counter `Tank+0x494`);
    9 -> `FUN_005454F0(x)` -> ctor `FUN_004EA740` (Grubber);
    10..12 -> `FUN_00547270(x,y,id-10,f)` -> ctor `FUN_004EE5C0` (**`Sexy::Breeder`** stages 0-2);
    else -> `FUN_00546FC0` -> `FUN_004EEF90(x, y, stage, facing)` (base Fish at stage id).
    **Successors are LIVE spawns** - every wrapper activates `FUN_00542EE0(obj, 1)` while the
    corpse used flag 0 (EV-0053; closes the EV-0051 "ghost vs live" question). Natural path:
    phase stays 100 while the corpse animates, `stage < 1` removes it silently; the revive
    branch needs an external writer setting phase `<= 10` - trigger not found yet (open Q).
  - Corpse physics (dbl fields): vx `+0x170` decays 0.03/tick toward 0; vy `+0x178` ramps
    +0.05/tick toward +2.0 (sink) when byte `+0x188` == 0, else toward -1.5 (wraps back to the
    +2.0 ramp at -1.5); jitter/drift `+0x198` (init 1.0, -0.02/tick, floor 0) is forwarded to
    the parent object at `+0x94` (+0x168) while stage `[+0x1A0] < 0x69`; horizontal `+0x168`
    += vx/speed, vertical `+0x160` += vy/speed (speed `+0x180`); clamps horizontal 10..540,
    vertical 85..370/310: 370 for ids 8/9, 310 for id 6, else 380; packed int copies
    `+0x30/+0x34` refreshed by `FUN_00564160` x2 + vtable slot 0xA4 (+164).
  - Ids >= 0x65 = pet corpses (pets can die and use the same drift/despawn path).
- Other death entry points (EV-0054): fish-family slot 88 `FUN_004D5F90` voices
  `FUN_00538610([0x8C])`, calls vtable `0x15C(0)`, derives facing from the sign of `+0x168`,
  forwards `+0x168/+0x170/+0x180` (velocity/speed), stage `+0x1A0` and parent `+0x94` to
  `FUN_005441F0` (corpse id = stage). Collector routines `FUN_004F2890` (Grubber code region;
  cleanup `FUN_004F2740(0)`), `FUN_004F3C60` (Penta region; `FUN_004F3AD0(0)`) and
  `FUN_004DD5D0` (`FUN_004DD530(0)`, corpse id = stage + 10) share the same spawn shape and
  run from creature hunger ticks `FUN_004F8F60` / `FUN_004F1340` once `FUN_004D69D0` (starve
  check: `+0xAC < 0`, demo thresholds -2159 / -4319 for types 7/8/9, non-demo hunger < 1)
  fires - written with region attribution only (class of the tick bodies open).
- Types 0xA-0xC = `Sexy::Breeder` (ctor `FUN_004EE5C0`, vtable 0x597814, Update 0x4F4180):
  stage `+0x1A0` param 0/1/2, side field `+0x168`/`+0x188` = +/-1.0, life/hunger `+0x1D4`
  (stage 0/1: rand%400+1000, else rand%200+800). Corpse ids 10-12 therefore revive as a
  Breeder one stage down (the `stage+10` accounting in `FUN_004DD5D0` matches).

## 8. Implementation spec for P4 (growth/death)

1. Fish entity: species + stage fields; observed stage starts: Guppy 0, Carnivore 5, Ultravore 6,
   all on the shared growth machine (Gekko/Sylvester/Ball/Bi spawn paths still open - decode
   before implementing those tanks).
2. Spawn defaults from `FUN_004DE370`: sizes 80x80, bounds (10..540 x, 95..370 y),
   vertical drift -0.5, speed class {2.0, 1.8, 1.6}, initial hunger 400-599 (Oscar 600-799),
   growth threshold 4-6 points (mode 5: 12-20), random initial facing/direction.
3. Growth: feed points `+0x1A4` vs `+0x1A8`; stage-up restarts points, plays grow anim
   (`+0x1CC = 10`); overshoot (mode 5 ? 8 : 15) x threshold -> stage 4 (diminutive/flash).
4. Feeding: accept only normal pellets (variant 0) or breeding pellets pre-stage-3, otherwise
   per-diet; nutrition per quality/species; star-potion specials (death/stage 3).
5. Death: hunger < -499 -> die() -> death sound 0x125, corpse animates/sinks until stage ends
   (then silent removal via detach slot 0x144), and a **live** successor object spawns via the
   id table (§4; the corpse revive-early trigger is not part of the natural death path - open).
6. Presentation: bounce/wobble from Update (P2.3 §5), flash alpha on hit (`+0xA0`),
   corpse phases 7/8/9, splat particles for predation when gore option on.
7. Corpse/Breeder support: corpse objects (type 0x1B) = inert spawned bodies with drift/sink
   physics, an id-selected live successor and a phase counter for an unidentified revive
   trigger. Breeder creatures (types 0xA-0xC) have stages 0-2, life field `+0x1D4` and corpse
   ids 10-12 (EV-0052/0054).
